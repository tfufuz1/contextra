- **Rust-Installation:** `crates.io` erreichbar, `static.rust-lang.org` nicht. Nutze `conda-forge` (`conda.anaconda.org` erlaubt) mit micromamba oder `apt` mit `rustc-1.89` / `cargo-1.89`.

Wenn Konnektoren zu Github bestehen, aktiviere Push damit du Änderungen direkt zu Github hinzufügen kannst. Du kannst nur über diese Konnektoren Pushen da du vom Webchat aus gestartet wurdest. Du agierst ein einer VM von Anthropic wenn du diese Repo klonen musstest. Wenn es unmöglich ist über Github die Änderungen zu Pushen dann liefere dem Benutzer in Chat eine ZIP-Datei vom root aus mit allen Änderungen. Sollte es vorkommen das Dateien gelöscht werden müssten lieferst du diese im Paket als leere Hüllen zum überschreiben.
