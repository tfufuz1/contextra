# `contextra-wire-fuzz` — Schnittstellenspezifikation

**Normbasis:** [SPEC-INTEGRATION](../SPEC-INTEGRATION.md).

## Vertrag

Fuzzt Wire-Versionen, DurablePosition, Cursor, Tickets und redigierte Fehler.

## Abnahme

Ungültige Instanz-/Stamp-Paare werden verworfen und keine sensitiven Felder geloggt.
