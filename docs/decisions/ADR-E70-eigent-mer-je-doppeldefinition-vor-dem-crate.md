# ADR-E70: Eigentümer je Doppeldefinition vor dem Crate-Schnitt (§4.11)

* **Status:** Akzeptiert (aus Spezifikation §13 E70)
* **Datum:** 2026-10-15

## Entscheidung
Eigentümer je Doppeldefinition vor dem Crate-Schnitt (§4.11).

## Begründung
Ohne Eigentümer driften Kopien auseinander (FE §3.7).

## Verworfen
Doppelte Typen dulden
