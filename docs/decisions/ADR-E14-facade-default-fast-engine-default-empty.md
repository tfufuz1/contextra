# ADR-E14: `facade.default = ["fast"]`, `engine.default = []`; `candle`

* **Status:** Akzeptiert (aus Spezifikation §13 E14)
* **Datum:** 2026-10-15

## Entscheidung
`facade.default = ["fast"]`, `engine.default = []`; `candle` opt-in; `rank` Pflicht.

## Begründung
Hülle ≤ 18 ist sonst unerreichbar.

## Verworfen
Default mit `candle`
