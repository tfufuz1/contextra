# ADR-E77: Tenant-ID-Herkunft: stdio mit Bindung beim Prozessstart (E18

* **Status:** Akzeptiert (aus Spezifikation §13 E77)
* **Datum:** 2026-10-15

## Entscheidung
Tenant-ID-Herkunft: stdio mit Bindung beim Prozessstart (E18). Andere Transporte brauchen ein eigenes ADR.

## Begründung
MP2 §19.1 ist nicht entworfen. Der Transport ist heute stdio.

## Verworfen
Bindung aus Tool-Argumenten
