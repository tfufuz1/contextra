# ADR-E29: Lizenz steuert nur das Ausstellen neuer Beweise; kein Downgr

* **Status:** Akzeptiert (aus Spezifikation §13 E29)
* **Datum:** 2026-10-15

## Entscheidung
Lizenz steuert nur das Ausstellen neuer Beweise; kein Downgrade, kein `open`-Blocker bei Ablauf (§5.15).

## Begründung
Löschpflicht darf nicht an Lizenzstatus hängen.

## Verworfen
Fail-closed `open` bei Ablauf
