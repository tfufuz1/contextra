# ADR-E02: Genau ein Ringmodell (Ring 0–4 + Tooling), maßgeblich §4.1,

* **Status:** Akzeptiert (aus Spezifikation §13 E02)
* **Datum:** 2026-10-15

## Entscheidung
Genau ein Ringmodell (Ring 0–4 + Tooling), maßgeblich §4.1, gespiegelt in `capabilities.toml`; Ordnung innerhalb eines Rings (§4.2).

## Begründung
Vier parallele Modelle verhindern ein eindeutiges Gate (F-18).

## Verworfen
„Layer 0–10" als zweites Ringsystem
