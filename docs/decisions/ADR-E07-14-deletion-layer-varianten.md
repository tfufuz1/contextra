# ADR-E07: 14-deletion-layer-varianten

* **Status:** Akzeptiert (aus Spezifikation §13 E07)
* **Datum:** 2026-10-14

## Entscheidung
Normativ sind 14 `DeletionLayer`-Varianten; sieben Beweisklassen sind eine Auditor-Sicht (§6.3).

## Begründung
Kein „7-Layer"-Modell deckt sich mit dem Code; Erweiterbar ohne Formatbruch.
