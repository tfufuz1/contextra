# ADR-E72: Jeder Arbeitspaket-Eintrag braucht einen Owner. Der Kalender

* **Status:** Akzeptiert (aus Spezifikation §13 E72)
* **Datum:** 2026-10-15

## Entscheidung
Jeder Arbeitspaket-Eintrag braucht einen Owner. Der Kalender wird pro Meilenstein festgelegt.

## Begründung
Ohne Owner und Kalender gibt es keine Verantwortlichkeit und keine Prüfung des Zeitplans.

## Verworfen
Schätzung ohne Owner
