# ADR-E63: API-Stabilität: vor 1.0 frei mit semver-Warnung; ab 1.0 bloc

* **Status:** Akzeptiert (aus Spezifikation §13 E63)
* **Datum:** 2026-10-15

## Entscheidung
API-Stabilität: vor 1.0 frei mit semver-Warnung; ab 1.0 blockierend (G-26).

## Begründung
Ports sind der Vertrag zwischen Ringen. Ungeprüfte Änderungen brechen Konsumenten still.

## Verworfen
Keine Stabilitätsregel
