# ADR-E16: contextra-crypto-ohne-shim-splitten

* **Status:** Akzeptiert (aus Spezifikation §13 E16)
* **Datum:** 2026-10-14

## Entscheidung
`contextra-crypto` wird ohne Shim gesplittet (§4.8).

## Begründung
Vor v0.1.0 keine externen Konsumenten; Beweiscode gehört nicht ins EP1-Binary.

## Verworfen
Rückwärtskompatibler Shim
