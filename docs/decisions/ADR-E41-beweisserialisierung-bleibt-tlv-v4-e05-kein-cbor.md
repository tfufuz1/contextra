# ADR-E41: Beweisserialisierung bleibt TLV v4 (E05). Kein CBOR-Export.

* **Status:** Akzeptiert (aus Spezifikation §13 E41)
* **Datum:** 2026-10-15

## Entscheidung
Beweisserialisierung bleibt TLV v4 (E05). Kein CBOR-Export.

## Begründung
Ein zweites Export-Format verdoppelt Kanonisierung und Testvektoren.

## Verworfen
CBOR-Export (ARCHITEKTUR_MASTERPLAN_v2 §7.8, ADVANCED §7.4)
