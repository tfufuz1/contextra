# ADR-E59: Zeitbasis: MAC-geschützter Monotonie-Anker im Manifest; Quar

* **Status:** Akzeptiert (aus Spezifikation §13 E59)
* **Datum:** 2026-10-15

## Entscheidung
Zeitbasis: MAC-geschützter Monotonie-Anker im Manifest; Quarantäne in Ticks; Rücksetzung fail-closed (§5.9).

## Begründung
Reine Wanduhr erlaubt eine Verkürzung der 72-h-Quarantäne (F-45).

## Verworfen
Reine Wanduhr
