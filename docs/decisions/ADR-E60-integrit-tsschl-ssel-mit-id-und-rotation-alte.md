# ADR-E60: Integritätsschlüssel mit ID und Rotation; alte Schlüssel ble

* **Status:** Akzeptiert (aus Spezifikation §13 E60)
* **Datum:** 2026-10-15

## Entscheidung
Integritätsschlüssel mit ID und Rotation; alte Schlüssel bleiben verify-only (§5.9).

## Begründung
Ohne Rotation ist ein Schlüsselwechsel nicht ohne Bruch der Kette möglich.

## Verworfen
Schlüsseltausch ohne Kette
