# Spec Delta P01 (WP-S1): CryptoRng, SecretBytes, and Signer Management

**Stand:** 2026-10-21
**Befunde:** F-01 (CSPRNG enforcement), F-10 (Signer key file management & single path resolution), F-22 (blocking I/O in async context)

---

## 1. Overview and Invariants

### 1.1 `CryptoRng` Trait and Separation (§7.4 / WP-S1)
- Added `pub trait CryptoRng: Send + Sync` in `contextra-ports::rng`.
- `CryptoRng` provides `fn fill_secret(&self, dest: &mut [u8]) -> Result<(), RngError>`.
- **Compile-time Separation:** Non-CSPRNG generators (`SystemRng`, `SeededRng`, `SplitMix64`) DO NOT implement `CryptoRng`.
- Implementation for `Arc<T> where T: CryptoRng + ?Sized` is provided for dynamic dispatch.
- `OsCryptoRng` in `contextra-sys` (backed by `getrandom`) and `OsEntropyRng` in `contextra-ports` are the sole production CSPRNG sources implementing `CryptoRng`.

### 1.2 `SecretBytes<const N: usize>` Container (§7.4)
- Container type wrapping `zeroize::Zeroizing<[u8; N]>`.
- Method `generate(crypto_rng: &dyn CryptoRng) -> Result<Self, RngError>` accepts strictly CSPRNG entropy sources.
- Implements automatic zeroization on drop, `ct_eq` for constant-time comparison, and redacted `Debug` / `Display` implementations (`[REDACTED]`).

### 1.3 Ed25519 Proof Signer Key Management (F-10, F-22)
- Single-path signer key resolution using `FileOrCsprngSignerSource`.
- Eliminates silent HOME directory fallbacks (`~/.contextra/proof_ed25519.key` removed).
- Enforces strict file permissions (`0600` on Unix) and explicit symlink rejection (`symlink_metadata`).
- Atomic key creation via `OpenOptions::new().write(true).create_new(true).mode(0o600)` prevents TOCTOU races.
- File I/O operations wrapped appropriately via `spawn_blocking` or sync storage threads.

## 2. Key Rotation Interface Definition (contextra-crypto)

Key rotation interfaces for deletion proof signers and key classes reside in `contextra-crypto`:

```rust
pub enum KeyClass {
    Active,
    Legacy,
    Revoked,
}

pub struct KeyId(pub [u8; 16]);

pub trait KeyRotationManager: Send + Sync {
    fn rotate_key(&self, class: KeyClass) -> Result<KeyId, ContextraError>;
    fn get_key_status(&self, key_id: &KeyId) -> Result<KeyClass, ContextraError>;
}
```
