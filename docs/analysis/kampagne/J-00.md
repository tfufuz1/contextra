## 4. Befunde

### J-00-F01 (S2 - Korrektheits-/Integritätsfehler): `contextra-wire` Kompilierungsfehler unter Rust 1.89.0

- **Schwere:** S2 (Integritätsfehler / Build-Blocker)
- **Datei:Zeile:** `crates/contextra-wire/src/contextra_generated.rs:326:5` (sowie 34 weitere Stellen in derselben Datei) [BELEGT]
- **Beweisstufe:** [GEMESSEN]
- **Erwartet:** `cargo check -p contextra-wire --locked` baut fehlerfrei durch.
- **Tatsächlich:** 35 Fehler `error[E0133]: call to unsafe function ... is unsafe and requires unsafe function or block`. Ursache: `crates/contextra-wire/src/lib.rs` deklariert `#![forbid(unsafe_code)]`, während der von `flatc` 2.0.8 autogenerierte Code `unsafe`-Methoden von FlatBuffers `Table::get` aufruft.
- **Ein-Zeilen-Reproduktionsbefehl:** `cargo check -p contextra-wire --locked`
- **Geschwister-Fundstellen (R7):** Alle autogenerierten Tabellenzugriffsmethoden in `crates/contextra-wire/src/contextra_generated.rs`.
- **Fix-Skizze:** `crates/contextra-wire` ist laut `capabilities.toml` eine ausgewiesene `unsafe_island = true`. Das Crate-Level `#![forbid(unsafe_code)]` in `crates/contextra-wire/src/lib.rs` muss entfernt bzw. durch gezielte Unsafe-Erlaubnisse oder Regenerierung der FlatBuffers-Bindings angepasst werden.
