## 4. Befunde

### J-10-F01: `debug_assert!`-Spezifische Panictests schlagen im Release-Profil fehl
- **Schwere:** S2 (Integritäts-/Testkorrektheitsfehler)
- **Datei:Zeile:** `crates/contextra-graph/src/csr/tests/basic_tests.rs:566, 584` [BELEGT]
- **Beweisstufe:** [GEMESSEN]
- **Erwartet:** Tests mit `#[should_panic]` bestehen unabhängig vom Compile-Profil.
- **Tatsächlich:** Im Release-Profil wird `debug_assert!` von rustc entfernt. Die Tests paniken nicht mehr und schlagen fehl.
- **Ein-Zeilen-Reproduktion:** `cargo test -p contextra-graph --release --lib -- test_wallclock_txid_debug_assert_panics`
- **Geschwister:** `test_sentinel_txid_zero_debug_assert_panics` in derselben Datei.
- **Fix-Skizze:** Testfunktionen mit `#[cfg(debug_assertions)]` annotieren, damit sie in Release-Testläufen übersprungen werden, oder explizite Runtime-Invariantenprüfung verwenden.

### J-10-F02: PPR Performance Benchmark-Schwelle schlägt im Release-Profil fehl
- **Schwere:** S2 (Korrektheits-/Schwellenwertfehler)
- **Datei:Zeile:** `crates/contextra-graph/src/ppr/tests/context_tests.rs:781` [BELEGT]
- **Beweisstufe:** [GEMESSEN]
- **Erwartet:** Forward-Push PPR erzielt im Release-Profil mindestens 50.0x Speedup gegenüber Dense Power Iteration.
- **Tatsächlich:** Im Testlauf wurde nur ein Speedup von 2.26x erreicht (Forward-Push 1.46ms vs. Dense 3.30ms), woraufhin `assert!(speedup >= expected_min_speedup)` fehlschlug.
- **Ein-Zeilen-Reproduktion:** `cargo test -p contextra-graph --release --lib -- test_forward_push_performance_benchmark_vs_dense`
- **Geschwister:** keine
- **Fix-Skizze:** Speedup-Schwellenwert an realistische VM-/Runner-Hardware anpassen oder als Benchmark-Harness auslagern, da Timing-Asserts in Unit-Tests auf variabler Hardware instabil sind.

### J-10-F03: Unbegründeter `#[ignore]` Test in `contextra-text`
- **Schwere:** S3 (Wahrheits-/Dokumentationslücke)
- **Datei:Zeile:** `crates/contextra-text/tests/alloc_profiler.rs:25` [BELEGT]
- **Beweisstufe:** [BELEGT]
- **Erwartet:** Ignorierte Tests tragen eine Begründung gemäß Systemkonvention (z. B. `#[ignore = "Begründung"]`).
- **Tatsächlich:** `run_profile_10k_documents` nutzt schlicht `#[ignore]` ohne Grund.
- **Ein-Zeilen-Reproduktion:** `cargo test -p contextra-text --test alloc_profiler -- --list --ignored`
- **Geschwister:** `crates/contextra-adapt/src/bandit.rs` (`bench_sherman_morrison_p95_latency` nutzt vorbildlich `#[ignore = "P95 Latency Benchmark Test"]`).
- **Fix-Skizze:** Attribut zu `#[ignore = "Allokations-Profilierungs-Benchmark für 10.000 Dokumente"]` erweitern.
