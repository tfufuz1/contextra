# Spec-Sync Fragment for K-01

## Section Number
§11.2 / KV-Cache Eviction & Attention Scoring Integration

## Old Text
The KV-cache eviction worker in `contextra-kvcache` initializes with a null attention score source and lacks dynamic segment-to-request mapping interfaces. Standard store eviction paths fall back to unweighted LRU ordering.

## New Text
The KV-cache eviction worker in `contextra-kvcache` exposes explicit segment-to-request registration interfaces (`register_segment_request` and `unregister_segment_request`) scoped per tenant to prevent cross-tenant attention score leakage. `TenantIsolatedKvStore` maintains a configurable default `AttentionScoreSource` via `set_attention_source` and `attention_source`, ensuring store-level eviction wrappers (`pop_lru`, `evict_lru_fair`) honor attention-weighted ranking without holding locks across external exporter invocations. Mappings are automatically purged upon segment eviction or removal to guarantee bounded memory growth.
