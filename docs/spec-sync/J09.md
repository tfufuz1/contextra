# Spec Sync Fragment for Prompt J09

## Overview
This fragment records specification alignment and audit bugfixes across `contextra-kvcache`, `contextra-vector`, `contextra-graph`, `contextra-checkpoint`, `contextra-avv-generator`, and `contextra-crypto`.

## Summary of Changes
1. **contextra-kvcache**:
   - Feature-gated `tests/kivi_aead_order_enforced.rs` under `cfg(any(feature = "kivi-quantization", feature = "kvcache-kivi-quant"))` matching module exports in `lib.rs`.
   - Fixed clippy `collapsible_if` and `unnecessary_map_or` (`is_some_and`) lints in `store.rs`.
   - Cleaned up unneeded `#[allow(dead_code)]` attributes and gated test/encryption-only helpers (`TenantState::tenant_id`, `insert_returning_evicted`, `get_segment_ref_mut`, `evict_lru_global`, `register_segment_mapping`).
2. **contextra-vector**:
   - Introduced `TombstoneSet` in DiskANN (`RoaringTreemap` without `docid-128`, `HashSet<u128>` with `docid-128`) to prevent 128-bit DocId truncation and collision.
   - Updated DiskANN WAL reader and mmap loading to handle 128-bit DocIds without truncation.
   - Added integration test `tests/diskann_docid128_tombstones.rs`.
3. **contextra-graph**:
   - Fixed `Edge` type imports in `csr/inner.rs` under `feature = "edge-reinforcement-learning"`.
   - Replaced `unreachable!` in `ppr.rs` with safe `PprAlgorithm::Auto` resolution.
   - Fixed manual range check clippy lint in `hyperedge_suggest.rs`.
4. **contextra-checkpoint**:
   - Added `cfg(loom)` mock I/O module in `hardlink_cloner.rs` enabling `RUSTFLAGS="--cfg loom" cargo check -p contextra-checkpoint` to compile.
5. **contextra-avv-generator & contextra-crypto**:
   - Added `#![forbid(unsafe_code)]` to `lib.rs` in both crates to satisfy `check-unsafe-islands`.
