# Spec-Sync Fragment for G-01

## Section Number
§21.2 / Y.1.2 — APPRH Gate Integration & Production Shadow Selector

## Old Text
Averaging-based Personalized PageRank for Hypergraphs (APPRH) runs exclusively as an isolated module behind feature `apprh-diffusion` without explicit selector integration or gate monitor hysteresis tracking in the PPR retrieval path.

## New Text
APPRH shadow-mode evaluation and production release are managed by an explicit instance-level `ApprhSelector` (`selector.rs`) coupled to `ApprhGateMonitor` (`gate_monitor.rs`). In `Shadow` mode, `ApprhSelector` returns authoritative Forward-Push PPR results while periodically observing sampled shadow comparisons (`shadow_compare_forward_push_vs_apprh`). Promotion to `Production` mode requires explicit release (`promote_to_production()`). If the monitor streak loses production readiness, `ApprhSelector` automatically demotes to `Shadow` mode with `tracing::warn!` hysteresis. Spec-compliant function `forward_push_apprh(graph, seeds, params, hyperedge_decay_factor) -> Result<AHashMap<EntityId, f32>, ContextraError>` enforces finite boundary validation on `hyperedge_decay_factor` $\in (0.0, 1.0]$ and guarantees bit-identical IEEE-754 score determinism across seed and graph insertion permutations.
