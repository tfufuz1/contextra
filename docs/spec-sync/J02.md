# Spec-Sync Fragment J02

## Spezifikationsänderung: SSTable Multi-Version Flush & Rotation (Abschnitt 18 / WP-02, WP-03, WP-16)

### Alter Text:
Flush schreibt MemTables als SSTables auf Festplatte, wobei pro Key jeweils nur die neueste Version in die SSTable übernommen wird. WAL-Rotation tauscht die WAL-Datei ohne Halten der Transaktionssperren.

### Neuer Text:
MemTable-Flush behält alle MVCC-Versionen eines Keys oberhalb der kleinsten gepinnten Snapshot-Sequenz (`SnapshotRegistry::min_active_seqno()`) sowie die neueste Version auf oder unterhalb dieses Floors. SSTables nutzen Format Version 2 für Multi-Version-Einträge in der Reihenfolge (`key ASC`, `seq DESC`).
Die WAL-Rotation und der MemTable-Tausch im Flush laufen unter `commit_mutex` und `state.write()`. Der WalCheckpoint-Eintrag im Manifest speichert den HMAC-Tip der alten WAL vor dem Swap.
