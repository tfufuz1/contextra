# Spec-Sync Fragment for J06

## Section Number
§20.2 / Engine Transaction 2PC Protocol

## Old Text
Engine multi-index transactions execute text and graph staging commits prior to writing the `CommitIntent::Pending` intent marker. If storage intent marker or commit fails, compensating calls are executed ad-hoc without unified LIFO ledger execution.

## New Text
Engine multi-index transactions execute atomic 2PC commit across storage, vector, text, and graph indices using a unified `CommitLedger` (LIFO stack). `CommitIntent::Pending` is written and committed to storage durably before index staging and commits occur. Writing `CommitIntent::Committed` uses bounded retry with backoff; on persistent failure, recovery checks transaction storage existence before executing index compensation.
