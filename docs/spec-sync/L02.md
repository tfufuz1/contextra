# Spec-Sync Fragment for L02

## Section Number
§18.3 / Engine Startup Lifecycle & Multi-Tenant Storage Wiring

## Old Text
Engine startup initializes `LsmStorage` and loads collection indices without validating storage SSI tracking capabilities or isolating collection storage paths per tenant.

## New Text
Engine startup initializes `LsmStorage`, validates storage SSI tracking capabilities (`supports_ssi_tracking()`), and executes consolidation intent cleanup. Tenant-scoped collection access via `collection_for_tenant` wraps the underlying storage engine in `TenantScopedStorage` to enforce strict key-level tenant isolation using `t:{tenant_id}:` key encoding (INV-TENANT-2) across get, search, scan, and deletion operations.
