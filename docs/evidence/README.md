# Contextra Evidence Directory (`evidence/`)

This directory contains execution evidence, baseline reports, audit logs, and metrics for Contextra.

## Directory Structure

- `evidence/baseline/`: Current baseline execution results generated by `tools/baseline/run_baseline.py`.
  - `<crate>.json`: Per-crate baseline evidence containing durations, test counts, command outputs, root cause attribution, and slowest tests.
  - `SUMMARY.json`: Summary overview of all workspace crates and workspace-wide command executions.
  - `ROOT_CAUSES.md`: Grouped table of compiler and clippy diagnostic root causes.
  - `logs/<crate>/`: Uncut raw execution logs for each crate command (compressed with `.log.gz` if >= 2 MB).
  - `logs/workspace/`: Raw execution logs for workspace-wide commands (`check`, `clippy`, `test`, `fmt`, `deny`, `audit`).

## Historical Baselines

- `evidence/baseline-a547a42/`: Historical baseline protocol from Commit `a547a42`.
- `evidence/baseline-2026-10-28/`: Historical baseline protocol from 2026-10-28.
