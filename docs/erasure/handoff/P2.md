# Handoff-Bericht: Aufgabe P2 (Swap-Sofortfix WP-5a und Rewrite mit Journal und Manifest WP-5)

> Status: Abgeschlossen · Datum: 2026-11-11 · Crate: `crates/contextra-erasure`

## 1. Ist-Befund vor Beginn

- **Swap-Pfad & DEK-Cache (`crates/contextra-erasure/src/vault/sealer.rs:37`):**
  - Vor der Änderung hielt `VaultSealer` Roh-Bytes `[u8; 32]` im `dek_cache` (`BTreeMap<KeyBuf, [u8; 32]>`).
  - `evict` (`sealer.rs:214`) überschrieb Werte mit `v.fill(0)`, jedoch ohne explizites `ZeroizeOnDrop` auf Puffern bei vorzeitigem Abbruch oder Exceptions.
  - Es existierte keine explizite atomare Speicher-Swap-Funktion (`safe_swap_buffers`) mit Fehlererkennung und Zeroizing bei Teilausfällen.
  - Es gab keine dauerhafte Handle-Vergiftung (`is_poisoned` / `poison()`) nach E/A- oder Synchronisationsfehlern.
- **Fehlende Rewrite-Mechanik (`crates/contextra-erasure/src/vault/`):**
  - In `crates/contextra-erasure/src/vault/` existierte noch kein Modul `rewrite/` bzw. `rewrite.rs`.
  - Da `crates/contextra-erasure/src/vault.rs` und `src/vault/mod.rs` nicht im Schreibrecht von P2 liegen, wurde die Rewrite-Implementierung regelkonform als Inline-Untermodul `pub mod rewrite { ... }` in `crates/contextra-erasure/src/vault/sealer.rs` abgelegt.

## 2. Getroffene Architekturentscheidungen

1. **WP-5a Speicher-Swap-Sofortfix:**
   - Einführung von `ProtectedDek` mit `#[derive(Clone, Zeroize, ZeroizeOnDrop)]` zur Kapselung von Schlüsseln im Cache.
   - Erweiterung von `VaultSealer` um `poisoned: Arc<AtomicBool>`, `is_poisoned(&self) -> bool` und `poison(&self)`.
   - Implementierung von `safe_swap_buffers(&self, dest: &mut [u8], src: &mut [u8], fail_at_step: Option<u8>) -> Result<(), SealerError>`, die bei jeglichem Fehler oder Fehler-Injektion BEIDE Puffer sofort vollständig nullt (`zeroize`), das Handle über `self.poison()` dauerhaft sperrt (Fail-Closed) und `SealerError` zurückgibt.
   - `RecordSealer`-Methoden (`seal`, `open`, `make_slots_durable`) prüfen `is_poisoned()` und verweigern den Zugriff permanent.

2. **WP-5 Blob-Rewrite mit Journal und Manifest (5-Phasen-Pipeline):**
   - **Phase 1 (`Planned`):** Intent mit Eindeutiger `rewrite_id`, `target_id`, `timestamp_nanos` und `pre_digest` wird im `RewriteJournal` atomar erfasst.
   - **Phase 2 (`Overwritten`):** Physisches Überschreiben der Ziel-Blobs über den neutralen Port `StorageBackend::purge`.
   - **Phase 3 (`Synced`):** Synchronisation und Fsync. Jeder Fehler vergiftet das Handle permanent (Invariante `INV-VAULT-FAILCLOSED-1`).
   - **Phase 4 (`ManifestUpdated`):** Atomare Aktualisierung des `RewriteManifest` mit neuer monotoner Version und `is_erased = true`.
   - **Phase 5 (`Committed`):** Journal-Eintrag wird als abgeschlossen markiert.

3. **Wiederanlauf und Crash-Recovery (`recover_and_reconcile`):**
   - Ein nach einem Absturz neu instanziierter Rewriter scannt das Journal nach unvollendeten Intents:
     - War Phase 4 bereits erreicht (`ManifestUpdated`), wird der Vorgang im Journal vollendet (`Committed`).
     - Brach der Vorgang vor Phase 4 ab (`Planned`, `Overwritten`, `Synced`), wird der Rewrite sicher zurückgerollt (`RolledBack`) und unfertige Daten im Backend neutralisiert/genullt, ohne Klartext zu exponieren.
   - Nach der Recovery stimmen Manifest und Journal deterministisch überein.

pub mod rewrite {
    #[derive(Debug, thiserror::Error, PartialEq, Eq)]
    pub enum RewriteError {
        Poisoned,
        JournalWrite(u8, String),
        BlobOverwrite(String),
        SyncFailure(String),
        ManifestUpdate(String),
        JournalFinalize(String),
        Recovery(String),
        InjectedCrash(u8),
    }

    #[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
    pub enum RewriteState {
        Planned,
        Overwritten,
        Synced,
        ManifestUpdated,
        Committed,
        RolledBack,
    }

    #[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
    pub struct RewriteIntent {
        pub rewrite_id: u64,
        pub target_id: String,
        pub timestamp_nanos: u64,
        pub state: RewriteState,
        pub pre_digest: [u8; 32],
    }

    #[derive(Clone)]
    pub struct RewriteJournal {
        pub fn new() -> Self;
        pub fn with_vfs(vfs: Arc<dyn Vfs>, journal_path: std::path::PathBuf) -> Self;
        pub fn record_intent(&self, intent: RewriteIntent) -> Result<(), RewriteError>;
        pub fn update_state(&self, rewrite_id: u64, new_state: RewriteState) -> Result<(), RewriteError>;
        pub fn get_intent(&self, rewrite_id: u64) -> Option<RewriteIntent>;
        pub fn uncommitted_intents(&self) -> Vec<RewriteIntent>;
    }

    #[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
    pub struct ManifestEntry {
        pub target_id: String,
        pub is_erased: bool,
        pub updated_at_nanos: u64,
        pub rewrite_id: u64,
    }

    #[derive(Clone)]
    pub struct RewriteManifest {
        pub fn new() -> Self;
        pub fn with_vfs(vfs: Arc<dyn Vfs>, manifest_path: std::path::PathBuf) -> Self;
        pub fn version(&self) -> u64;
        pub fn get_entry(&self, target_id: &str) -> Option<ManifestEntry>;
        pub fn update_entry(
            &self,
            target_id: String,
            is_erased: bool,
            updated_at_nanos: u64,
            rewrite_id: u64,
        ) -> Result<u64, RewriteError>;
    }

    #[derive(Debug, Clone, PartialEq, Eq)]
    pub struct RewriteOutcome {
        pub rewrite_id: u64,
        pub target_id: String,
        pub manifest_updated: bool,
        pub journal_committed: bool,
    }

    #[derive(Clone)]
    pub struct BlobRewriter {
        pub fn new(
            journal: RewriteJournal,
            manifest: RewriteManifest,
            backend: Arc<dyn StorageBackend>,
            clock: Arc<dyn Clock>,
        ) -> Self;
        pub fn is_poisoned(&self) -> bool;
        pub fn poison(&self);
        pub fn journal(&self) -> &RewriteJournal;
        pub fn manifest(&self) -> &RewriteManifest;
        pub async fn execute_rewrite(
            &self,
            rewrite_id: u64,
            target_id: &str,
            pre_digest: [u8; 32],
            crash_after_step: Option<u8>,
        ) -> Result<RewriteOutcome, RewriteError>;
        pub async fn recover_and_reconcile(&self) -> Result<usize, RewriteError>;
    }
}
