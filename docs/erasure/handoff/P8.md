## 3. Getroffene Entscheidungen

1. **Synchroner Port ohne Async/Runtime-Kopplung:** `ResidueScanner` ist als rein synchroner Trait definiert (`fn scan_residue`, `fn canary_probe`). Keine Tokio- oder Async-Abhängigkeit im Messpfad.
2. **Datensparsamkeit bei Fundstellen:** `ResidueFinding` meldet nur die Schicht `LayerId`, die strukturelle `OffsetClass` (z. B. `VectorNode`, `BacklinkEntry`, `NeighborList`, `QuantizedData`, `AuxiliaryIndex`, `EntryPoint`) und die Anzahl `count: u64`. Es werden niemals Rohbytes oder Klartextinhalte extrahiert oder im Befund exponiert.
3. **Strenge Positiv- und Negativkontrolle:**
   - Ein Messergebnis ist ungültig (`PositiveControlFailed`), wenn das vorab eingebrachte Canary-Muster (`canary_probe`) nicht detektiert wurde.
   - Nach der Löschung muss die Trefferanzahl exakt 0 sein (`post_erase_matches == 0`). Jeder Befund führt fail-closed zu `ResidueDetected`.
4. **Fehlertaxonomie mit Phasenbezug:** Fehlertyp `ResidueMeasurementError` (keine Stringfehler) bindet jede Fehlerursache an die `ResiduePhase` (`Init`, `PreEraseScan`, `PositiveControl`, `PostEraseScan`, `WitnessFinalization`).
5. **Kryptographischer Zeugen-Digest:** `ResidueWitnessDigest` erzeugt einen BLAKE3-Digest über Schichtkennung, Dokument-ID, Fingerprint, Canary-Hash, geprüfte Einheiten und Scandauer.

## 4. Exakte öffentliche Signaturen

In `crates/contextra-erasure/src/measure/residue.rs` bereitgestellt und über `crates/contextra-erasure::measure` re-exportiert:

```rust
pub trait ResidueScanner: Send + Sync {
    fn layer(&self) -> LayerId;
    fn canary_probe(&self, canary: &[u8]) -> Result<bool, ResidueMeasurementError>;
    fn scan_residue(&self, query: &ResidueQuery) -> Result<ResidueScanResult, ResidueMeasurementError>;
}

pub struct ResidueQuery {
    pub doc_id: DocId,
    pub target_fingerprint: [u8; 32],
}

pub struct ResidueFinding {
    pub layer: LayerId,
    pub offset_class: OffsetClass,
    pub count: u64,
}

pub struct ResidueScanResult {
    pub findings: Vec<ResidueFinding>,
    pub total_matches: u64,
    pub units_checked: u64,
}

pub struct ResidueWitnessDigest {
    pub layer: LayerId,
    pub duration: Duration,
    pub units_checked: u64,
    pub digest: [u8; 32],
}

pub struct ResidueMeasurementCoordinator<'a> {
    scanner: &'a dyn ResidueScanner,
    clock: &'a dyn Clock,
}

impl<'a> ResidueMeasurementCoordinator<'a> {
    pub fn new(scanner: &'a dyn ResidueScanner, clock: &'a dyn Clock) -> Self;
    pub fn verify_positive_control(&self, canary: &[u8]) -> Result<(), ResidueMeasurementError>;
    pub fn measure_after_erasure(
        &self,
        query: &ResidueQuery,
        canary: &[u8],
        pre_erase_matches: u64,
    ) -> Result<ResidueMeasurementReport, ResidueMeasurementError>;
}
```
